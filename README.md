# ⚽ MyAlbum (Em Desenvolvimento)

MyAlbum é uma aplicação backend para gerenciamento de figurinhas da Copa do Mundo, permitindo o controle de usuários, coleções, figurinhas repetidas e progresso do álbum.

O sistema foi desenvolvido em Python utilizando FastAPI, SQLAlchemy e SQLite, seguindo uma arquitetura organizada e baseada em Programação Orientada a Objetos.

## Tecnologias

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Uvicorn
